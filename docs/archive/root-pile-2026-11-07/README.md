## Where things live (the answer to "where is X stored?")

  `corpus`: read, not maintained).
- Past work docs: `work-docs/`.
- Session handoffs: `docs/archive/HANDOFF-*`.
- Point-in-time analysis: `docs/analysis/` (strand-governed: every doc must be
  referenced from a surface that gets read, or carried as exempt debt in
  `docs/strand-exempt.txt`).
- Build specs: `docs/specs/`; product requirements: `docs/prd/`; cross-repo
  contracts: `docs/standards/`; architecture decisions: `docs/adr/`.
- Live roadmap: `TODO.md` at the root. Review policy: `REVIEW.md` at the root.
- Reading order: `docs/INDEX.md`. Full inventory: `docs/DOCMAP.md` (generated by
  `python tools/docmap/docmap.py write`).
- New documents go in the subtree above that matches their kind, never at the
  root and never in a new top-level directory without a row in
  `docs/coverage-map.txt` and a purpose in `docs/dir-purpose.txt`.
